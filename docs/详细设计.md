# 系统详细设计
## 1. 系统概述
本系统为校园二手集市智能助手，采用前后端分离架构：Vue3 + SpringBoot，集成多模态大模型、RAG检索知识库、Agent智能对话能力。面向校园买卖双方，实现图片生成商品文案、同款比价、智能客服自动回复、交易风险提示等功能。

## 2. 系统架构设计
整体分为三层：前端展示层、后端业务服务层、AI能力层
1. **前端展示层（Vue3）**
图片上传、页面渲染、商品展示、聊天交互，接收后端返回AI生成内容、比价数据、Agent回复。
2. **后端业务层（SpringBoot）**
接收前端请求，业务逻辑处理，MySQL数据持久化；模块包含用户模块、商品模块、聊天模块、知识库模块、管理员模块。
3. **AI能力层**
- 多模态大模型：解析上传图片，识别物品类型、成色，生成商品标题与描述
- RAG检索：基于品类、成色检索历史成交记录，统计价格区间
- Agent智能调度：处理买家咨询，结合商品上下文自动回复，风控检测，输出交易风险提醒

## 3. 模块划分
1. 用户认证模块：账号登录、身份识别，区分buyer/seller/admin三种角色
2. 商品AI生成模块：图片上传，调用多模态模型生成商品信息，联动RAG获取参考价格
3. 商品管理模块：商品发布、分页查询、商品详情、下架
4. RAG比价知识库模块：历史成交记录查询、管理员维护成交数据
5. Agent智能对话模块：消息存储、Agent自动回复、交易风险检测
6. 管理员后台模块：商品审核下架、知识库数据维护

## 5. AI业务流程设计
### 5.1 图片生成商品信息流程
1. 前端上传图片文件发送至后端
2. 后端接收图片，调用多模态大模型API，识别物品，输出标题、描述、物品分类、成色
3. 使用分类+成色条件查询RAG知识库trade_history表，筛选同类历史成交记录
4. 统计价格区间，计算建议参考价格
5. 将标题、描述、建议价格、历史比价数据返回前端展示，用户确认后发布商品

### 5.2 RAG同款比价检索流程
1. 传入物品分类、成色参数
2. 查询trade_history，过滤匹配记录
3. 对价格做统计，得到价格上下区间
4. 返回历史成交列表和价格区间给前端展示

### 5.3 Agent智能对话调度流程
1. 买家发送咨询消息，提交后端
2. 后端读取对应商品上下文信息，交给Agent
3. Agent限定回答范围：仅回答二手商品相关问题；识别私下转账、脱离平台交易等高风险话术
4. 生成自动回复内容，附加反诈、隐私保护风险提示
5. 将用户消息与Agent回复存入chat_message表，返回前端聊天页面展示

## 6. 时序简要说明
1. 卖家登录 → 上传图片 → AI生成商品信息 → 确认发布 → 商品入库
2. 买家登录 → 浏览商品 → 查看同款比价 → 发起咨询 → Agent自动回复
3. 管理员登录 → 后台查看商品 → 下架违规商品、维护成交知识库

## 7. 异常处理
1. AI接口调用超时：前端提示AI服务暂时不可用，可以手动填写商品信息
2. 图片格式错误：校验图片后缀与大小，拒绝非法文件
3. 权限校验：买家不能操作商品发布，管理员才可维护知识库
4. 风控拦截：识别诱导私下交易话术，弹出风险警告
