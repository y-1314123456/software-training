# 系统操作说明书
## 1. 系统简介
校园二手集市智能助手，面向在校学生，支持卖家上传图片由AI自动生成商品文案、查看同款二手历史价格；买家浏览商品、智能咨询，Agent自动回复并提供交易反诈提醒；管理员负责商品管理与成交知识库维护。

## 2. 环境准备
- 浏览器：Chrome / Edge
- 系统访问地址：前端 http://localhost:5173
- 后端服务地址：http://localhost:8080

## 3. 卖家操作流程
1. **登录系统**
输入卖家账号密码，进入首页。

2. **AI生成商品信息**
点击【发布商品】，点击上传闲置物品图片，点击【AI生成】按钮。
系统调用多模态模型自动识别物品，生成商品标题、描述；同时查询RAG历史成交库，展示同款历史成交价格区间与AI建议售价。

3. **编辑并发布商品**
查看AI生成内容，可以手动修改标题、描述、价格。确认信息无误，点击【提交发布】，商品存入数据库，在商品列表展示。

4. **我的商品管理**
进入【我的商品】页面，可以查看本人发布全部商品；支持下架不需要继续售卖的商品，下架后买家无法浏览该商品。

## 4. 买家操作流程
1. **登录系统**
输入买家账号密码登录。

2. **浏览商品与查看比价**
首页展示所有上架商品；点击商品卡片进入详情页。
商品详情页展示商品信息，下方展示同款历史成交记录，查看二手价格区间作为参考。

3. **智能咨询（Agent聊天）**
商品详情页点击【智能咨询】打开聊天窗口。
输入问题发送，系统Agent会自动回复商品相关问题，每次对话附带交易风险提示。
> 风险提示示例：请勿脱离平台私下转账交易，谨防诈骗，保护个人手机号、住址隐私。

4. **查看聊天记录**
聊天窗口保存历史对话，可随时回看用户消息与Agent回复。

## 5. 管理员操作流程
1. **管理员登录**
使用admin账号登录，进入管理员后台页面。

2. **商品管理**
查看平台全部上架商品；发现违规商品，点击下架，下架后商品不再对外展示。

3. **RAG知识库维护**
进入知识库管理页面，可以新增、编辑、删除历史成交记录。新增数据会作为比价数据源，影响同款比价结果。

## 6. 常见操作问题
1. AI生成卡住：检查后端服务是否正常启动，大模型API密钥配置是否正确，网络是否连通。
2. 图片上传失败：图片不能过大，支持jpg/png格式。
3. Agent不回复：确认后端服务正常，检查商品ID是否正确。
4. 看不到比价数据：知识库trade_history表缺少对应品类测试数据。
