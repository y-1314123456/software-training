# 系统安装部署文档

## 环境要求

| 软件 | 版本 |
|----|----|
| JDK | 17 |
| Maven | 3.8.6 |
| MySQL | 8.x |
| Node.js | 20.12.0 |
| npm | 10.5.0 |

## 后端部署步骤

1. 创建MySQL数据库，执行 `docs/sql/init.sql` 脚本完成建库建表，导入测试数据。
2. 修改 backend 下 `application.yml` 配置：数据库连接地址、账号密码、大模型API密钥。
3. 进入 backend 目录执行编译运行

```bash
mvn clean install
mvn spring-boot:run
