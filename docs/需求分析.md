# 系统功能分析说明书

## 1. 项目背景

校园内学生存在大量教材、数码、宿舍闲置物品交易需求。传统二手交易存在痛点：卖家拍照后不会撰写商品文案；买家不了解二手物品合理行情；买卖咨询消息经常无人回复，交易存在诈骗、隐私泄露风险。

校园二手集市智能助手，基于多模态大模型、RAG知识库、Agent对话，降低卖家发布门槛，提供行情参考，实现智能自动应答，并增加交易风险提示。

## 2. 角色分析

| 角色 | 说明 |
|----|----|
| 卖家 | 上传物品图片，AI生成商品文案与建议价格，发布、管理自己的闲置商品 |
| 买家 | 浏览商品，查看同款比价，发起咨询，接收Agent自动回复 |
| 管理员 | 管理商品，维护历史成交知识库，风控规则管理 |

## 3. 功能性需求

1. 拍照生成文案：上传图片，多模态大模型自动生成商品标题、描述，结合历史成交数据输出建议定价。
2. 同款比价：RAG检索历史成交记录，返回同品类物品历史成交价格区间给用户参考。
3. 智能撮合与自动回复Agent：买卖对话过程，Agent自动回答常见咨询，辅助供需撮合。
4. 交易风险提示：识别高危交易行为，弹窗反诈、隐私保护、线下交易安全提醒。
5. 商品管理：卖家发布、下架自己的闲置商品。
6. 商品浏览：买家查看商品列表、商品详情。
7. 聊天记录保存：保存用户消息以及Agent自动回复记录。
8. 管理员管理：商品审核、维护比价知识库数据。

## 4. 非功能性需求

1. 安全：Agent客服输出内容合规；禁止输出诱导私下交易内容；保护用户隐私信息。
2. 数据口径：AI给出的参考定价来源于历史成交记录，不作为绝对成交价，明确标注仅参考。
3. 易用性：页面操作简单，图片上传、AI生成操作步骤少，适配校园学生使用。
4. 性能：图片上传与AI接口响应控制在合理时间。
5. 可维护性：AI相关模块代码解耦，方便更换大模型API。
